## About

I am a Data Science student at the **University of Information Technology — VNU-HCM**, focused on building practical AI systems that connect models, data, APIs, and automation workflows.

- 🧠 **LLM & RAG** — retrieval, reranking, fine-tuning, evaluation, and grounded generation
- 🇻🇳 **Vietnamese NLP** — datasets and benchmarks for metaphor, legal, and healthcare language
- 👁️ **Computer Vision** — real-time detection, image embeddings, and change-aware inference
- ⚙️ **AI Automation** — intelligent workflows, API integrations, and maintainable backend services
